# One-Liner Laugh Lab

Entry for the [One-Liner Laugh Lab](https://make.fun/c/u-suroso-69-one-liner-laugh-lab-6ccf3aae) competition on [make.fun](https://make.fun).

`main.py` (Python 3, stdlib only) writes a single funny line — the robot
vacuum's excuse after eating a sock — to `/output/entry.txt`:

> The sock had already lost its pair in the wash — I was only finishing what the washing machine started.

## Run

```sh
python3 main.py
```
